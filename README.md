# AVPick project page (local preview only)

A single static page in the style of the Nerfies project page: plain HTML + Bulma CSS, no build step.
Every asset (CSS, fonts, scripts, images, video) is stored under `static/` and referenced with relative
paths; the page loads nothing from the network.

## Local preview

```bash
cd avpick-page
python3 -m http.server 8000
# then open http://localhost:8000 in a browser
```

Use the local server rather than opening `index.html` directly: the demo timeline loads its prediction
JSON with `fetch`, which browsers block for `file://` pages.

Class colors are defined once in `static/css/index.css` (`--c-speech`, `--c-vocals`,
`--c-instruments`, `--c-sound`) and match the colors used in the paper figures.

## Orchard artwork

The hand-drawn background (sky with sun and clouds, fruit trees on the hill in the header, a smaller
orchard in the footer) and the fruit icons of the class legend are generated by
`../avpick-page_tools/make_orchard.py` (kept outside this folder). Each fruit carries the icon of one class
in its fixed color and is a different fruit: speech = blue apple with a speech bubble, vocals = green pear
with a microphone, instruments = purple plum with music notes, sound = orange with a speaker. The script draws the scene as SVG, renders it with Playwright's Chromium, and writes
transparent WebP/PNG files into `static/images/`. Edit tree positions, fruit counts or colors in the script
and rerun `python3 make_orchard.py` to regenerate.

## Demo: data format and adding clips

The demo sits right below the header (it replaces the teaser figure) and shows the clip of the paper's
teaser figure: `static/videos/demo_clip.mp4` (720p H.264/AAC,
re-encoded from the original 1080p file) with `static/videos/demo_clip_predictions.json`, which holds the
36 intervals of the AVPick-prediction RTTM used to draw the teaser lanes (label `vocal` renamed to
`vocals`). The poster `static/images/demo_clip_poster.jpg` is the frame at 01:16.

Below the lanes, a frame-level view draws the same predictions as a 4-row grid of cells (one cell =
`FRAME_HOP` = 0.1 s in `demo.js`) centered on the current time; it slides with playback and seeking, and
the current frame is outlined.

The demo block is:

```html
<div class="demo-player" data-video="demo-video" data-predictions="static/videos/demo_clip_predictions.json">
  <video id="demo-video" ...>
    <source src="static/videos/demo_clip.mp4" type="video/mp4">
  </video>
  ...
</div>
```

`python3 -m http.server` does not answer byte-range requests, so browsers cannot seek a video served by
it directly. `demo.js` detects this and loads the whole file into the page once (status line: "Loading the
full video to enable seeking…"); with a range-capable web server this step is skipped.

1. **Video.** Copy the clip into `static/videos/` and point the `<source>` elements (and `poster`) at it.
   A web-friendly encode used for the current clip:
   `ffmpeg -i in.mp4 -vf scale=-2:720 -c:v libx264 -preset slow -crf 28 -maxrate 900k -bufsize 1800k -pix_fmt yuv420p -c:a aac -b:a 128k -map_metadata -1 -movflags +faststart out.mp4`.
   Poster frame: `ffmpeg -ss 76 -i out.mp4 -frames:v 1 static/images/clip_poster.jpg`.
2. **Predictions.** Write a JSON file and set `data-predictions` to its path. `demo.js` accepts either
   frame-level scores or ready-made segments; times are in seconds from the start of the video.

   Frame-level scores (what the model outputs; segments are obtained by thresholding):

   ```json
   {
     "duration": 20.0,
     "frame_hop": 0.01,
     "classes": ["speech", "vocals", "instruments", "sound"],
     "thresholds": {"speech": 0.5, "vocals": 0.5, "instruments": 0.5, "sound": 0.5},
     "scores": {
       "speech":      [0.02, 0.03, 0.91, ...],
       "vocals":      [...],
       "instruments": [...],
       "sound":       [...]
     }
   }
   ```

   Frame *i* covers `[i * frame_hop, (i + 1) * frame_hop)`. A frame is active when its score is
   `>= thresholds[class]` (0.5 if the class has no threshold). The score curve is drawn faintly behind
   the active segments.

   Segments only (e.g. already post-processed predictions):

   ```json
   {
     "duration": 20.0,
     "segments": {
       "speech":      [[0.6, 4.2], [5.0, 7.4]],
       "vocals":      [[8.0, 14.6]],
       "instruments": [[7.2, 15.4]],
       "sound":       [[0.0, 2.4]]
     }
   }
   ```

   If both `segments` and `scores` are given, `segments` decides the colored bars and `scores` only draws
   the curve. If the JSON contains `"placeholder": true`, a "synthetic placeholder" status line is shown. The timeline length follows the video duration once it is loaded, otherwise
   `duration` from the JSON.
3. **Several clips.** Duplicate the whole `demo-player` block with a different `id` on the `<video>` and a
   matching `data-video`; each block is initialized independently.

## Before publishing

This folder is meant for local preview only. Asset URLs in `index.html` carry a `?v=N` suffix to bypass browser caches; bump it after regenerating
images or editing CSS/JS. Before any public release, fill in the placeholders above
and re-check that no identifying information remains.
